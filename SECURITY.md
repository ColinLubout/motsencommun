# Sécurité

## Signaler une faille

Si vous trouvez une faille de sécurité dans Mots en commun (le site ou ce dépôt), **ne la publiez pas dans une issue**. Signalez-la en privé, avec le signalement de vulnérabilité de GitHub :

**<https://github.com/ColinLubout/motsencommun/security/advisories/new>**

Le signalement reste privé jusqu'à ce que la faille soit corrigée. Décrivez ce que vous avez trouvé, comment le reproduire, et ce qu'un attaquant pourrait en faire.

Mots en commun est un projet bénévole : nous répondons dès que possible et vous tenons au courant de la correction. Merci de ne pas faire d'essais qui gêneraient les lecteurs ou abîmeraient les données : pas de déni de service, pas d'accès aux comptes des autres.

Les bugs ordinaires vont dans les [issues publiques](https://github.com/ColinLubout/motsencommun/issues).

# Security

## Reporting a vulnerability

If you find a security problem in Mots en commun (the site or this repository), **please don't post it in an issue**. Report it privately, through GitHub's private vulnerability reporting:

**<https://github.com/ColinLubout/motsencommun/security/advisories/new>**

The report stays private until the problem is fixed. Please describe what you found, how to reproduce it, and what an attacker could do with it.

Mots en commun is a volunteer project: we reply as soon as we can and keep you informed about the fix. Please don't run tests that would disrupt readers or damage data: no denial of service, no access to other people's accounts.

Ordinary bugs go to the [public issues](https://github.com/ColinLubout/motsencommun/issues).
